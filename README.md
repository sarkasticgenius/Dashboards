# HM Nexus dashboard demo

Five futuristic dashboard views with illustrative, embedded demo data. No production API, Supabase connection, credentials, or live telemetry is included.

## GitHub Pages
Upload this folder's contents to the root of a separate public repository. In Settings > Pages choose Deploy from a branch, main, / (root).

For automatic screen playback append `?display=wall&rotate=1#wall` to the published site URL. Views rotate every 20 seconds. Use the fullscreen button on the display.

## Custom domain later
Set the custom domain in repository Settings > Pages and configure its DNS using GitHub's instructions. No dashboard rebuild is needed.

## Data sources
All dashboard metrics and charts are sample values embedded in the HTML JavaScript. Only the clock uses the current time. Google Fonts supplies typography, not operational data. GitHub Pages hosts these files; it does not collect data from the HM application.
